# 开发运行

## 后端

```bash
cd backend
go mod tidy
go run ./cmd/server --config ./configs/config.example.yaml
```

默认服务地址：

- `GET http://127.0.0.1:9998/healthz`
- `POST http://127.0.0.1:9998/admin/login`
- `GET http://127.0.0.1:9998/v1/models`

首次启动会按 `security.bootstrap_admin` 创建初始管理员。`security.bootstrap_api_key` 为空时不会自动创建 API Key，需要登录后台后创建。

## 前端

```bash
cd frontend
pnpm install
pnpm dev
```

默认访问：

- `http://127.0.0.1:5173/admin`

## 账号组

后端启动时会确保存在默认账号组 `default`。没有显式绑定分组的账号和 API Key 会进入默认组。

账号组用于限制 API Key 的账号调度范围：

- API Key 通过 `group_id` 绑定一个账号组。
- 账号通过 `group_ids` 绑定一个或多个账号组。
- `/v1/*` 请求会根据命中的 API Key 只在对应账号组内选择可用账号。
- `PUT /admin/groups/:id/accounts` 是替换式更新，只保留请求体中传入的成员。
- 删除普通账号组时，组成员关系会被删除，绑定到该组的 API Key 会转回默认组。

常用接口：

```bash
ADMIN_TOKEN='<admin_token>'

curl http://127.0.0.1:9998/admin/groups \
  -H "Authorization: Bearer ${ADMIN_TOKEN}"

curl http://127.0.0.1:9998/admin/groups \
  -H "Authorization: Bearer ${ADMIN_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"name":"team-a","description":"Team A account pool","enabled":true}'

curl -X PUT http://127.0.0.1:9998/admin/groups/2/accounts \
  -H "Authorization: Bearer ${ADMIN_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"members":[{"account_id":1,"enabled":true,"priority":100}]}'

curl -X PUT http://127.0.0.1:9998/admin/api-keys/3 \
  -H "Authorization: Bearer ${ADMIN_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"group_id":2}'
```

## PostgreSQL

本地可通过 compose 启动 PostgreSQL：

```bash
docker compose --profile postgres up -d postgres
```

再将后端配置切换为：

```yaml
database:
  driver: postgres
  dsn: host=127.0.0.1 user=notion2api password=change-me dbname=notion2api port=5432 sslmode=disable TimeZone=Asia/Shanghai
```
