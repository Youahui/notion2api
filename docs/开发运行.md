# 开发运行

## 后端

```bash
cd backend
go mod tidy
go run ./cmd/server --config ./configs/config.example.yaml
```

默认服务地址：

- `GET http://127.0.0.1:8787/healthz`
- `POST http://127.0.0.1:8787/admin/login`
- `GET http://127.0.0.1:8787/v1/models`

首次启动会按 `security.bootstrap_admin` 创建初始管理员。`security.bootstrap_api_key` 为空时不会自动创建 API Key，需要登录后台后创建。

## 前端

```bash
cd frontend
pnpm install
pnpm dev
```

默认访问：

- `http://127.0.0.1:5173/admin`

## PostgreSQL

本地可通过 compose 启动 PostgreSQL：

```bash
docker compose --profile postgres up -d postgres
```

再将后端配置切换为：

```yaml
database:
  driver: postgres
  dsn: host=127.0.0.1 user=notaion2api password=change-me dbname=notaion2api port=5432 sslmode=disable TimeZone=Asia/Shanghai
```
